A program that writes one funny line about a meeting that should have been an email — for make.fun's "The Meeting That Should Have Been an Email" bounty ($2 in USDC).

The line: *"The meeting's only decision was to send an email summarizing the meeting that should have been the email."*

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: no fetch, no randomness, no clock — every run writes the same 105 characters.
